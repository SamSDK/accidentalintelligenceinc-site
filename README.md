# Accidental Intelligence Inc — site

Parent company site. Dependency-free static `index.html` (inline CSS, no build step), deployed via GitHub Pages.

**Status:** placeholder holding page only — links out to the live Desker site. Full site (company overview, product pages) not yet designed.

## Deploy

Push to `main` — GitHub Pages auto-rebuilds. Custom domain is set via the `CNAME` file (`accidentalintelligenceinc.com`); DNS is managed at the registrar (Namecheap), not here.
